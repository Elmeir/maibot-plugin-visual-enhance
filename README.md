# 视觉增强（maibot-plugin-visual-enhance）

> 给麦麦补上三块「看」的能力：**看懂动图的每一帧、按问题重新看图、看懂视频在说什么**。纯插件实现，不改宿主一行代码。

- 插件 ID：`github.elmeir.visual-enhance`
- 宿主要求：MaiBot ≥ 1.2.4（maibot-plugin-sdk ≥ 2.8.1）
- 依赖：Pillow、aiohttp、httpx、bilibili-api-python（自动安装）
- 作者：[Elmeir](https://github.com/Elmeir) ｜ License：[MIT](LICENSE)
- 版本：见 [_manifest.json](_manifest.json) ｜ 变更见 [CHANGELOG.md](CHANGELOG.md)

## 功能

- **GIF 动图分镜**：动图交视觉模型前，按时序把各帧合成到同一张网格图（默认 9 帧，可按运动量自适应），每帧带序号——看到动画的内容与时序，而不是只看到第一帧；落库前恢复原图，重复 GIF 零延迟
- **动漫角色识别**（可选，默认开）：描述命中动漫关键词时送 [AnimeTrace](https://ai.animedb.cn/zh) 识图，把「角色《作品》」追加进描述
- **图片重看**：首遍描述不够时，麦麦可带**具体问题**重新看图（含表情包）
- **视频理解**：聊天里出现 B 站/抖音链接时，自动把视频信息、章节要点与官方 AI 总结附加到上下文（不发额外回复），也可由麦麦主动解析

## 安装

```bash
cd /你的部署目录/plugins
git clone https://github.com/Elmeir/maibot-plugin-visual-enhance.git
# 重启麦麦
```

> 目录名保持 `maibot-plugin-visual-enhance`：配置在插件目录内的 `config.toml`，换目录名会丢配置。

## 配置

WebUI 插件页分 **主页 / 帧合成 / 输出图像 / 动漫识别 / 图片重看 / 视频理解 / 调试** 七个页签，各项均有中文标签与说明，保持默认即可使用。

| 页签 | 关键项 |
|---|---|
| 图片重看 | 图片重看开关、含表情包、回溯小时数、识图任务名、识图模型名（可选） |
| 视频理解 | 官方 AI 总结、抖音解析、群聊/私聊附加；**视频凭据**（B站分字段填 Cookie、抖音整串填 Cookie） |
| 调试 | 调试日志开关（开启后诊断信息以 INFO 输出，日志搜「视觉增强」） |

完整字段与默认值见 [config.example.toml](config.example.toml)。

## 使用

- **动图**：群友发 GIF 时自动分镜；
- **重看**：追问图片细节时，planner 会带问题重看；
- **视频**：群里发链接即自动附加总结，麦麦可直接参与讨论。

## 常见问题

| 现象 | 处理 |
|---|---|
| 视频没有 AI 总结 | 官方 AI 总结**需要登录态**：在「视频理解 → 视频凭据」填 Cookie（B站填 SESSDATA 等值的**值本身**；抖音填整串）；填完保存即清缓存重试 |
| 重看返回「没有可用的图片」 | 图片超出回溯时间/被清理，或只有表情包而关闭了「含表情包」 |
| 分镜没生效 | 只处理普通图片组件里的多帧 GIF；表情包走宿主原生链路 |
| 日志报能力不可用 | manifest 已声明；重载插件后仍报请检查宿主授权 |

## 边界与说明

- 分镜描述由宿主后台异步识别后回填，同图再次出现零延迟；
- 重看按需触发一次额外 VLM 调用（不是每张图都跑）；
- 视频解析会访问 B站/抖音接口（外发链接本身，不含聊天内容），Cookie 仅存本地；
- 任何环节失败一律原样放行，不阻塞消息链。
